# Playwright-SauceDemo
End-to-end UI automation framework using Playwright for testing SauceDemo workflows with scalable design and modern testing practices.

This project is a Playwright-based end-to-end (E2E) UI automation framework designed to validate core user workflows of the SauceDemo web application, a standard platform used for practicing web automation.

The framework demonstrates modern UI testing practices such as:

    Browser automation using Playwright
    Page Object Model (POM) for maintainability
    Structured test scenarios covering real user journeys

The automation suite validates key SauceDemo functionalities including login, product selection, cart operations, and checkout processes—common workflows used in real-world testing scenarios .

The framework is built with a focus on:

    Scalability and modular design
    Readable and maintainable test scripts
    Reusability through abstraction layers
    Faster test execution using Playwright’s parallel capabilities
    HTML reports with execution details
    Screenshots/videos on failure 
    Has been integrated with GitHub using Github Actions
